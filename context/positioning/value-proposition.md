# PaidHR Value Proposition by Persona

Built only from `context/docs/research/` (checked 2026-11-09). Source tags: **[co]** company.md, **[cu]** customers.md, **[mk]** market.md, **[vo]** voice.md. Personas defined in `context/icp/personas.md`.

## Champion: HR / People lead

| | |
|---|---|
| Job to be done | Run payroll, records, requests and reviews for a growing team without chasing approvals |
| Pain | Slow handling of "leave requests, loans, salary advances and expense reimbursement"; a tool that only did payroll [cu] |
| Gain | "Do less work managing your people": records, requests and approvals in HR Tools & Workflows; OKRs and reviews in the same platform [vo], [co] |
| Proof | Nikky Taurus HR & Admin Manager: processes "have become seamless" [cu]. Kredete Head of People: "more effective in managing employee information, setting OKRs and managing team activities" [cu] |

## Economic buyer: CEO / founder

| | |
|---|---|
| Job to be done | Get staff paid and taxes and pensions remitted correctly, without spending CEO time on it |
| Pain | Manual payroll, manual remittances, chasing confirmation [cu]. Penalty exposure under NTA 2025: 40% for failure to deduct, 10% plus interest for failure to remit [mk] |
| Gain | Statutory remittance "on autopilot"; payroll "in less than 5minutes" [vo], [cu] |
| Proof | Famasi CEO: "saved me at least 3hours of productive time" [cu]. "₦934M in PAYE filed and ₦754M in pension processed in 2025", 100% on time [co] |

## Influencer: Finance / payroll admin

| | |
|---|---|
| Job to be done | Pay accurately on the new tax bands, reconcile, and keep the ERP in sync |
| Pain | Spreadsheets and bank files; old tax bands producing incorrect deductions; retyping data [vo], [mk] |
| Gain | Payroll journals pushed to ERP; payroll API; tax-law-ready payroll [co]; multi-state remittance [sg] |
| Proof | "Fully updated for Nigeria’s new tax law, effective 1 January 2026" [co]. ISO 27001 certified, NDPA registered [co]. No finance-buyer testimonial found (gap) |
